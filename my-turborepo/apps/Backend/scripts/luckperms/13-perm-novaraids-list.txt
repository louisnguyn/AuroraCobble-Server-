# Grant novaraids.list to every rank group.
#
# Set per-group on purpose: the website assigns ranks with
# `lp user <name> parent set <role>`, which replaces all parents, so a ranked
# player no longer inherits LuckPerms' `default` group. Granting only on
# `default` would miss everyone who owns a rank.
#
# Also run 07-parent-add-default.txt so future perms on `default` inherit.
#
# Run: npx tsx scripts/rcon-batch.ts scripts/luckperms/13-perm-novaraids-list.txt

lp group default permission set novaraids.list true
