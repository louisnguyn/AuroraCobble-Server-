# Rank prefixes using the Asteryn rank pack bitmap font.
# Codepoints come from assets/minecraft/font/default.json in the pack.
# `\uXXXX` is expanded by rcon-batch.ts before sending.
#
# &f before the glyph matters: colour codes tint bitmap glyphs, so white keeps the
# icon's own colours. Trailing space separates the icon from the player name.
#
# All priorities are 100 and no weights are set: the website assigns ranks with
# `lp user <name> parent set <role>`, so a player holds exactly one group and there
# is never a tie to break.
#
# Requires the pack to be live via server.properties. Use the MERGED pack that also
# contains the Battle Pass GUI (U+E001-E006) and Cobblemon models - the standalone
# rank-icon pack would drop those.
#   resource-pack=<direct download url>
#   resource-pack-sha1=<sha1 of whichever zip you host>
# Without it clients see a missing-glyph box instead of the icon.
#
# Run: npx tsx scripts/rcon-batch.ts scripts/luckperms/02-group-prefixes-glyph.txt
