# OPTIONAL — chain the shop rank ladder so each rank inherits the one below.
#
# Website uses `lp user <name> parent set <role>` (replaces parents). With this
# chain, one parent is enough to keep lower-tier perms.
#
# Shop: member → noob → elite → pro → master → hero → onichan → ultimate → overlord → god
# VIP (separate overlay groups): player → vip → mvip → svip → uvip → legend → titan
#
# Run: npx tsx scripts/rcon-batch.ts scripts/luckperms/03-ladder-inheritance.txt

lp group noob parent add member
lp group elite parent add noob
lp group pro parent add elite
lp group master parent add pro
lp group hero parent add master
lp group onichan parent add hero
lp group ultimate parent add onichan
lp group overlord parent add ultimate
lp group god parent add overlord

# VIP overlay chain (not shop ranks)
lp group vip parent add default
lp group mvip parent add vip
lp group svip parent add mvip
lp group uvip parent add svip
lp group legend parent add uvip
lp group titan parent add legend
