# Make every rank group inherit LuckPerms `default`.
# After this, permissions set on `default` apply to all ranks.
#
# Needed because the website uses `lp user <name> parent set <role>`,
# which replaces parents — ranked players no longer sit in `default` directly.
#
# Run: npx tsx scripts/rcon-batch.ts scripts/luckperms/07-parent-add-default.txt
