# Grant essentialcommands.randomteleport to every rank group.
#
# Set per-group on purpose: the website assigns ranks with
# `lp user <name> parent set <role>`, which replaces all parents, so a ranked
# player no longer inherits LuckPerms' `default` group. Granting only on
# `default` would miss everyone who owns a rank.
#
# `default` is included anyway so players with no group still get it.
#
# Run: npx tsx scripts/rcon-batch.ts scripts/luckperms/04-perm-randomteleport.txt

lp group default permission set essentialcommands.randomteleport true
